# 命名与绘图约定

这些是本仓库的个人约定，不声称是 Cadence 或 IPC 官方标准。具体尺寸以目标器件 datasheet 的推荐 land pattern 和实际工艺要求为准。

## 文件与器件名称

- 原生模型名使用 ASCII 字母、数字和下划线；统一前缀 `MY_`，避免与外部库冲突。
- `Part_ID` 使用稳定编号，例如 `R-0001`、`C-0001`、`IC-0001`、`CONN-0001`、`MECH-0001`；不要把易变参数编码进编号。
- `.dra` 与 `.psm` 使用相同文件名主干；器件记录的封装名与 `.psm` 主干一致。
- 格式示例：`MY_SOIC8_P127_BODY390_R01`。约定尺寸数字为 mm × 100；示例表示 1.27 mm 间距、3.90 mm 本体宽，几何修订 01。
- 标准阻容可用 `MY_R_0603_R01`；本仓库 `0402/0603/0805` 均指英制尺寸代码，不能与公制同名代码混淆。
- QFN 名称应区分引脚数、间距、本体尺寸及 EP 版本；连接器优先按厂商型号命名。
- 焊盘示例 `MY_SMD_RECT_100X060_R01` 表示 1.00 × 0.60 mm；通孔焊盘还应体现孔径、镀孔类型和形状。
- 重命名封装或焊盘时在 Cadence 内更新引用并重新生成；不要只依赖文件系统重命名。

## 绘图约定

- 库几何优先用 mm；导入旧模型时先确认其单位，不直接按显示数值复制。
- 原点按封装类型一致选择：规则 SMD 一般采用本体中心；连接器按定位和装配需求选择并记录。
- 丝印保留 Pin 1、极性与可读外形，避免压焊盘或阻焊开窗。
- 使用合适的标准 class/subclass 表达装配外形、丝印和 place bound；不要把正式制造图形随意画在用户层。
- 阻焊与钢网设置要结合制造工艺；EP 的钢网分窗属于需要单独检查的设计内容。
- 原理图 IC 优先按功能组织引脚；引脚编号、电气类型及隐藏电源脚必须准确。
- 一个通用符号可以被多个采购器件复用，但每条器件记录应明确自身的 MPN、参数与实际封装。

## 共享依赖

更改共用 `.pad` 可能影响多个封装。影响尺寸、孔或制造输出时，应使用新名称/修订，并逐个验证受影响封装；不要默默修改历史已用模型。
