# 第三方来源与许可

来源可包括器件厂商官网、模型服务、官方开源硬件仓库及自行绘制。知名项目或官方发布不代表每个模型都适合本项目制造条件。

每个器件记录：原始 URL、来源版本/commit、目标完整料号、datasheet 版本、修改说明和验证状态。

本框架未替仓库所有者选定开源许可证，也不替第三方模型重新授权。增加实际模型前记录其许可；公开下载可用不等于可以重新公开分发。按原许可保留必要的署名和说明，许可未确认的资料暂存在本地 `incoming/`。

Datasheet 优先记录官方 URL；仅在允许再分发时提交 PDF。自身绘制且拟公开的模型，可由仓库所有者确定相应许可证后增加明确说明。

BeagleBoard 参考源：

- [BeagleBone Black 官方设计仓库](https://github.com/beagleboard/beaglebone-black)
- [BeagleV-Fire 官方设计仓库](https://github.com/beagleboard/beaglev-fire)

提取前核对具体版本的许可，提取后核对目标器件编号、焊盘、钢网、单位及共享焊盘名称。
